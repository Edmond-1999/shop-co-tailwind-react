# SHOP.CO React Homepage

A responsive SHOP.CO-style fashion storefront built with React, Tailwind CSS, Redux Toolkit, React Router, and the DummyJSON Products API.

## Technologies

- React + Vite
- Tailwind CSS v4
- Redux Toolkit + React Redux
- React Router
- DummyJSON API
- Async/await with `createAsyncThunk`

## Run the project

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Features

- Responsive homepage matching the supplied SHOP.CO design
- Tailwind CSS utility classes instead of component CSS files
- Product data fetched asynchronously from DummyJSON
- Redux store for product state and loading/error states
- Search products from the navigation bar
- Product grid, shop page, and product detail page
- Responsive mobile navigation
- Reused images/resources supplied with the project archive
